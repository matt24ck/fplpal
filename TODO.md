- [x] **Multi-GW transfer planner** — shipped 27 Jul 2026 (BUILDLOG §24): `engine/optimize/transfers.py` multi-period MILP (FT banking linearized, −4 hits, sell-price rule, discounting), `replay_season_frozen` + `backtest/planner_sim.py` harness, `plan_transfers` tool + `POST /transfers/plan` + Planner UI cards + chat card + grounding eval (8/8). **Acceptance passed: 2,152 pts on the 2025/26 replay vs the myopic bot's 2,020** (+132; every sweep config beat it; real average 1,895). - [x] **Full multi-season backtest harness** — shipped 28 Jul 2026 (BUILDLOG §28): `backtest/harness.py` replays 2023-24/2024-25/2025-26 point-in-time with per-season scoring configs and the PLAN §8 metric suite. Remaining knobs for later: planner γ across seasons (needs per-season frozen replays + sims), ceiling-aware captaincy (model pick ~6-8 pts/GW vs hindsight ~17-18).
- [x] **Live accuracy monitoring** — shipped 28 Jul 2026 (BUILDLOG §29): `engine/accuracy.py` freezes every visible GW's per-fixture projections (plus FPL's `ep_next` from the same snapshot) after each pipeline run and refuses to overwrite once that GW's deadline passes; after each played-GW ingest it rescores all frozen GWs against realized rows (PLAN §8 suite at player-GW level, DGW-collapse, postponements disclosed, `ep_next` horizon-gated) into `data/accuracy/`.
